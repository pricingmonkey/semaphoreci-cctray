semaphoreci-cctray

A cctray feed server for SemaphoreCI.

API

  • /{org}/cctray: cctray feed for all projects in an organization
  • /{org}/{project}/cctray: cctray feed for a single project

Authentication

You need a Semaphore API Token. You can create or regenerate your token by visiting your account page.

The Semaphore API Token must be sent with all requests using the HTTP Authorization header, with this format:

Authorization: Bearer {api_token}

Example with curl:

curl -H "Authorization: Bearer {api_token}" "http://{semaphoreci-cctray-hostname}/{org}/cctray"
